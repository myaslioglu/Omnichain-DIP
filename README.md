# Omnichain Decentralized Insurance Protocol (DIP)

## Overview
A **Centralized Omnichain Finality System** integrating **gasless transactions, zk-KYC, multi-chain staking, swaps, and decentralized insurance**.

### Features:
- **Omnichain Finality Ledger** (Bitcoin, Ethereum, Solana, Cosmos)
- **Gasless Transactions** using **Account Abstraction (ERC-4337)**
- **zk-KYC for Privacy-Preserving Identity Verification**
- **Multi-Chain Swaps & Staking**
- **Automated Liquidity Provisioning (Uniswap, PancakeSwap, Wormhole)**
- **Decentralized Insurance Protocol for Liquidity Protection**
- **Governance DAO for Claim Approvals**

## Installation
```sh
git clone https://github.com/YOUR_USERNAME/Omnichain-DIP.git
cd Omnichain-DIP
npm install
```

## Deploy Smart Contracts
```sh
cd backend
npx hardhat run scripts/deployTestnet.js --network goerli
```

## Run Frontend
```sh
cd frontend
npm start
```

## Deploy Mobile App
```sh
cd mobile
npx react-native run-android
```
